
# PLP Python Week 4

This repository contains my Week 4 Python functions assignment.

## Files

- `welcome.py` - Contains a welcome() function that creates greeting messages for different names.
- `toolbox.py` - Contains double(), is_pass(), and greet() functions and tests each function.

## Reflection

The `greet()` function was the hardest to write because it uses an optional greeting parameter with a default value. I had to understand how the default `"Hello"` is used when no other greeting is provided.
